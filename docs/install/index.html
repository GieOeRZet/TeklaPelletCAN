TeklaPelletCAN — instalator WWW

Wgranie firmware przez USB bezpośrednio z przeglądarki — bez ESPHome, bez instalowania czegokolwiek na komputerze.

Wymaga przeglądarki Chrome, Edge lub Opera na komputerze (Web Serial). Telefony i Firefox/Safari nie są obsługiwane przez tę metodę — na nich użyj ręcznego wgrania (niżej).

1. Podłącz urządzenie

Podłącz moduł TeklaPelletCAN do komputera kablem USB. Jeśli to pierwsze wgranie na nowym module (lub wcześniej był na nim inny firmware, np. ESPHome), instalator zapyta o wymazanie flash przed wgraniem — potwierdź.

2. Zainstaluj najnowszą wersję

Przycisk poniżej pobierze i wgra najnowszą wydaną wersję firmware (pełny obraz: bootloader + partycje + aplikacja). Po zakończeniu urządzenie uruchomi się automatycznie.

Alternatywa: ręczne wgranie (esptool)

Jeśli Twoja przeglądarka nie wspiera Web Serial (np. Firefox, Safari, telefon), wgraj ten sam obraz ręcznie:

pip install esptool
esptool --chip esp32c6 --port /dev/ttyUSB0 write_flash 0x0 teklapelletcan-factory.bin

Plik teklapelletcan-factory.bin — pobierz z najnowszego wydania (ten sam plik, który wgrywa instalator powyżej).

Po wgraniu

Urządzenie uruchomi własny portal konfiguracyjny WiFi (sieć TeklaPelletCAN-XXXX). Dalsze kroki — w dokumentacji pierwszego uruchomienia.

TeklaPelletCAN jest niezależnym, otwartym firmware (ESP-IDF) — ESPHome nie jest wymagane do niczego w tym projekcie.
