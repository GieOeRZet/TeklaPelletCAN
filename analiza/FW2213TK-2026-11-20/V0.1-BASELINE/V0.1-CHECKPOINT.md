# TeklaPelletCAN V0.1 checkpoint — 2026-11-20

This checkpoint is intentionally marked EARLY DEVELOPMENT / BASELINE.

The project has a reliable reverse-engineering base for:
- firmware identity and address mapping,
- startup/LZ77,
- parameter dictionary,
- access levels,
- HomeView,
- parameter read/write,
- CAN mapping tables,
- buffer/time layer,
- first physical CAN layer.

It is NOT yet a 1:1 reproduction.

The next phase is not to write the emulator first. The next phase is to finish the machine-readable model of all screens, navigation, CAN messages, assets and persistence. The emulator and HA card should then be generated from that model.
