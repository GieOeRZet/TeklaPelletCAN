# DRZEWO MENU igneoTouch v2.213 TE (HARD z emulacji; [?] = niezweryfikowane)

**EKRAN GŁÓWNY** (czas, dzień tyg., obraz kotła, temperatura/stan palnika, tryb AUTO)
- Kafelki dolne: **MENU** | paliwo (np. 180 kg) -> dialog "Paliwo" (+/-, kg, czas, OK) | płomień (stan palnika; kłódka = brak zezwolenia 0x2006) | Ogrzewanie 1 | Ogrzewanie 2 | Woda | **zasilanie** -> okno trybów (Kocioł on/off; suwaki trybu Ogrzewanie n / Woda użytkowa: off / eco / harmonogram / komfort)
- Kafel AUTO (prawy górny) -> okno z temperaturami komfort/eco (suwaki) lub komunikat "W tym trybie temperatura zadawana jest automatycznie."

**MENU** (nagłówek: "< EKRAN GŁ.", tytuł MENU, poziom dostępu)
Poziom 0 (13 wierszy przy pełnej konfiguracji), poziom >= 1 dodaje wiersze oznaczone [L1+]:
1. **Kocioł** -> ekran KOCIOŁ (m.in. energia łącznie, T. powrotu, ciśnienie, moc dmuchawy) -> kafel ustawień -> **NASTAWY** (lista parametrów wg poziomu)
2. **Palnik** -> ekran PALNIK (spalanie kg/h, moc kW/%, jasność, spaliny, tlen, T. palnika, obroty) -> NASTAWY
3. **Ogrzewanie obwód 1..4** (gdy 0x2105 >= n) -> ekran OGRZEWANIE n (temperatura, tryb, "Ochrona kotła" [L1+]) -> **PROGRAM** (tygodniowy: Pn Wt Śr Cz Pt So Nd, godziny 0–24) / **NASTAWY**; okno temperatur komfort/eco z suwakami
4. **Ciepła woda użytkowa** (0x2106) -> WODA -> PROGRAM / NASTAWY; okno temperatur
5. **Solary** (0x2108) -> SOLARY -> NASTAWY
6. **Bufor** (0x2107) -> BUFOR (temperatury góra/dół, [L1+] "0%") -> NASTAWY
7. **Kaskada** (gdy 0x350C != 0) -> KASKADA (MASTER, SLAVE 1..2/3, stopień mocy) -> NASTAWY
8. **Dodatkowy magazyn paliwa** (gdy 0x3525 != 0) -> MAGAZYN PALIWA (schemat, silniki 1 i 2) -> NASTAWY
9. **Historia alarmów** -> HISTORIA ALARMÓW (NR, KOD, tekst, Powstanie, POTWIERDŹ, status; strzałki)
10. **Informacje o programie** -> INFO (wersja "igneoTouch v2.213 TE", nazwa kotła "Bio Compact 10kW", "videRoom PIN", "Controller by Estyma (www.estyma.pl)")
11. **Konfiguracja** -> lista (uśrednianie temp. zewn., temp. przełączania na lato, kalibracja czujnika zew., rezerwa zbiornika paliwa, ... ; poziom 2 +HALL Activated, Request reset alarm memory; od poziomu 1 także 0x2105..0x2108, typ modułu, profil itd.)
12. **Poziom menu (PIN)** -> okno "Wpisz PIN" (4 cyfry, +/-, OK): 0900 -> L1, 0999 -> L2
13. [L1+] **Język (Language)** [wartość "PL"] -> wybór języka (PL, EN, LT, SK, CZ, ES, RO, EST) [?]
14. [L1+] **Alarm dźwiękowy** [przełącznik, PID 0x3506]
15. [L1+] **Test wyjść** -> ekran testu wyjść [? nie uchwycony — nazwy w eksploracji przesunięte]
16. [L1+] **Statystyki** -> STATYSTYKI (Licznik rozpaleń, Średni czas rozpalania [s], Średnia moc palnika z 50 godzin [%], Czas pracy podajnika 1/2 [h], Całkowite zużycie paliwa [kg], ...)
17. [L1+] **Sieć** -> SIEĆ (lista modułów/urządzeń CAN — w emulacji bez partnerów puste linie) [?]
18. [L1+] **Internet** -> INTERNET (SSID, PASSWORD, SERIAL, PIN, WiFi, Zmiany zdalne, ikona zasięgu)

Ekrany "NASTAWY" (lista): wiersz liczbowy -> dialog edycji (suwak min–max, -/+, OK; wysyła CAN 0x584); wiersz przełącznika zmienia wartość; separatory z ikoną klucza i cyfrą poziomu dzielą grupy poziomów.
